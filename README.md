## 👋 Olá, eu sou o Matheus

Profissional de tecnologia com foco em **Análise de Dados e Business Intelligence**. Desenvolvo dashboards, indicadores, consultas SQL, modelagem de dados e automações, sempre com o objetivo de **transformar dados em informações estratégicas** que apoiem a tomada de decisão.

Gosto de unir **análise, tecnologia e resolução de problemas** para criar soluções eficientes e orientadas a resultados.

> 🎯 **Buscando oportunidades como Analista de Dados Júnior ou Analista de BI Júnior.**

## ⚡ O que eu faço

| 📊 Business Intelligence | 🗄️ Dados & SQL | ⚙️ Automação & IA |
|:---|:---|:---|
| Dashboards e relatórios gerenciais em Power BI | Consultas SQL (JOIN, GROUP BY, subqueries) | Fluxos de integração com n8n e Power Automate |
| KPIs, indicadores e análises de desempenho | Modelagem dimensional e Star Schema | Integração entre sistemas via APIs |
| Medidas DAX e transformação com Power Query | ETL, tratamento e limpeza de dados | Soluções com modelos de IA (OpenAI) |
| MoM, Curva ABC, ticket médio | PostgreSQL e SQL Server | Apps low-code com FlutterFlow |
